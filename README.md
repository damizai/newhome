# 个人主页项目

这是一个简单的个人主页项目，使用HTML、CSS和JavaScript构建。

## 项目结构

```
.
├── index.html          # 主页面
├── css/
│   └── style.css      # 样式文件
├── js/
│   └── main.js        # JavaScript文件
└── README.md          # 项目说明文件
```

## 功能特点

- 响应式设计，适配各种屏幕尺寸
- 平滑滚动导航
- 现代化的UI设计
- 简洁的项目展示区域

## 如何使用

1. Fork或下载本项目
2. 直接可以部署在CFpages
3. 部署完成等待一会就可以打开了
4. 根据需要修改内容和样式

## 自定义

- 在 `index.html` 中修改页面内容
- 在 `css/style.css` 中调整样式
- 在 `js/main.js` 中添加交互功能

## 技术栈

- HTML5
- CSS3
- JavaScript (ES6+)
